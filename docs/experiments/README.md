# experiments — 실험 로그

무엇을 시도해봤는지 기록한다. **실패한 접근도 반드시 남긴다.**
같은 막다른 길을 두 번 걷지 않기 위한 문서다.

## 형식

파일명: `YYYYMMDD-<slug>.md`

```markdown
# <실험 제목>

- 일자:
- 목적: 무엇을 확인하려 했나
- 방법: 어떻게 시도했나
- 결과: 성공/실패 + 측정값
- 결론: 채택 여부, 후속 조치
```

## 예정된 실험

- Phase 5 착수 전: 평면 그래프 face 탐색 프로토타입 (자동 폐합 타당성 검증, R-2)
- Phase 1: 10만 엔티티 렌더 성능 (Canvas 2D vs WebGL 승격 판단 기준)
