# 0001 — 아키텍처 결정을 ADR로 기록한다

- 상태: 채택
- 일자: 2026-08-28

## 맥락

S-CUBE는 사실상 1인 개발이다 (리스크 R-12). 되돌릴 수 없는 기술 선택의 근거가
사람 기억에만 남으면, 유지보수 시점에 "왜 이렇게 했지"를 복원할 수 없다.

## 결정

되돌리기 어려운 아키텍처 선택마다 ADR(Architecture Decision Record) 1건을
`docs/decisions/NNNN-<slug>.md` 로 남긴다.
형식: **맥락 / 결정 / 근거 / 대안 / 결과**.

## 근거

- 문서 3계층 원칙 (README = 무엇을·어떻게 / decisions = 왜 / experiments = 시도)
- 감리·검증 중심 도구를 만들면서 개발 과정 자체가 추적 불가능하면 모순이다.

## 대안

- 커밋 메시지에만 의존 → 검색성·맥락 부족으로 기각
- 위키 → 저장소 밖 이탈, 오프라인 원칙 위배로 기각

## 결과

이후 모든 되돌릴 수 없는 선택(프레임워크, 렌더링 방식, 배포 방식 등)은
merge 전에 ADR을 동반한다.
