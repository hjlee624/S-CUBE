# 수량 계산 유형 분류 — 사연댐 BOQ 기반

사연댐 안전성 강화사업 BOQ(903행)의 전체 공종을 분석해 **S-CUBE가 도면에서 산출 가능한
계산 유형**으로 분류한 결과. 옹벽 하나를 세워도 콘크리트(㎥)·거푸집(㎡)·비계(㎡)·
동바리(공㎥)·철근(TON)이 함께 나오며, 각각 계산 방식이 다르다 — 양단면평균법 하나로는
BOQ의 일부만 커버된다는 문제의식에서 출발.

## 계산 유형 8종

| # | CalcType | 계산식 | 단위 | 도면 취득 | 지원 / core 빌더 |
|---|---|---|---|---|---|
| 1 | `section-length` | 단면적 × 연장 (양단면평균법/각주법) | ㎥ | 횡단면 폐합영역 + 측점 연장 | ✅ 핵심 (Phase 3) · `sectionLength` |
| 2 | `area-thickness` | 면적 × 두께 | ㎥ | 평면 폐합영역 + 규격의 t | ✅ · `areaThickness` (두께=규격, 하드코딩 금지) |
| 3 | `area` | 폐합영역 면적 직접 | ㎡ | 평면/사면 폐합영역 클릭 | ✅ (Phase 2, 측정값 직결) · HATCH 면적은 파서 대기(R-6) |
| 4 | `contact-length` | 접촉폭(둘레) × 연장 — **파생 면적** | ㎡ | 단면에서 접촉변 선택 × 구간 연장 | ⚠ `contactLength` — 접촉변 자동판별은 P4-9-1 |
| 5 | `length` | 선형 연장 직접 | m | 선/폴리라인/치수 클릭 | ✅ (Phase 2, 측정값 직결) |
| 6 | `count` | 개수 집계 | EA·개소·본·공·주 | 심볼/블록 카운트 (클릭 집계) | ⚠ `countTimes` — **자동 카운트 미지원**(수동), Phase 5 P5-17/18 |
| 7 | `ref` | 다른 항목 참조 파생 (합·차·계수) | 좌동 | 도면 무관 — 항목 수식 | ✅ (FormulaNode: `applyLoss`/`convertUnit` 등) |
| 8 | `manual` | 수동 입력 | 식·hr·mth·회 | 도면 무관 | ✅ 입력만 (FR-4.7, const) |

> **구현 정합**: core `calc.ts`는 6빌더(`sectionLength`/`areaThickness`/`contactLength`/
> `countTimes` + 직교 수식자 `applyLoss`·`convertUnit`)로 위 8유형을 매핑한다.
> `CalcType` 리터럴 유니온(03-DATA-MODEL §6)과 `TakeoffEditor` 선택가능 유형을 1:1 대조
> 테스트로 커버리지를 고정한다. ⚠ 표시는 자동 취득이 미완(수동/보강 대기)인 유형.

**단위 환산은 유형과 직교**: `conversions`(단위중량 ㎥→TON, 정척 m→본, kg/m)와
`lossRate`(할증)를 어느 유형에든 덧씌운다. 철근 = 콘크리트체적 `ref` × 철근비(kg/㎥)
→ TON 환산, 또는 길이 × 단위중량(D13=0.995kg/m).

## BOQ 공종 → 유형 매핑 (대표)

### 1. section-length — 단면×연장 (BOQ 최대 물량군)
흙깎기(보통토사/리핑암/발파암 전 유형), 흙쌓기, 터파기(측구·기계), 되메우기 및 다짐,
RIP RAP, 무근/철근콘크리트 타설(수로·옹벽 등 선형 구조물), 콘크리트 깨기(철거),
가물막이 철거, 측구터파기

### 2. area-thickness — 면적×두께
표토제거(T=20cm), 쇄석포설(t=150mm), 콘크리트 표층 포설(T=20cm — BOQ 실수식
`=758.5*0.2` 확인), 아스팔트 표층(t=5~8cm), 보조기층, 절토사면녹화(t=4/10cm)

### 3. area — 직접 면적
벌개제근·뿌리뽑기·벌목, 성토면/비탈면 고르기, 암반청소, 사면녹화(Seeding),
부직포·차수시트·비닐깔기, 비탈면숏크리트(T=100mm, 발주단위 ㎡), 낙석방지망,
슬래브 양생·면고르기, 콘크리트 치핑, 미끄럼방지포장, 융착성 도료

### 4. contact-length — 접촉둘레×연장 (파생)
**거푸집**(유로폼/합판 — 단면 접촉변 × 연장, 높이 구간별 분리), **시스템비계**(외벽
둘레 × 높이, 개월·높이 규격), **시스템/목재 동바리**(수평면적 × 높이 = 공㎥),
스페이서(수직=벽체 거푸집 연동/수평=기초면적 연동), 낙하물방지공, 가설방음벽

### 5. length — 연장
배수관(PVC·파형강관·판형·다발관·주철관·강관), U형플륨, 측구(산마루/U형/L형),
지수판, 신축이음(실링), 안전난간, 가드레일(지주·레일), 오탁방지막, 펜스류, 사다리,
경고테이프, 수평배수공·천공(개수×깊이로도 산출)

### 6. count — 개수
다웰바, 집수정·맹암거 구조물(개소), ROCK ANCHOR/Rock Bolt(공), 교량받침, 스틸
그레이팅, 배수문비(조), 날개벽, 강관 부설·접합(본/개소), 밸브, 조경 식재(주/본), 제설함

### 7. ref — 항목 참조 파생 (BOQ 실수식 다수 확인)
직접잔토처리 = Σ흙깎기, 순성토운반 = 흙쌓기−흙깎기(`=C116-C110`), 건설폐기물 상차 =
Σ깨기, 임목폐기물 상차 = 임목파쇄, 철근 구입·운반 = 가공조립 × 1.03(할증),
쇄석자갈 = 되메우기 × 1.04, 폐기물 처리(TON = 체적×밀도 환산)

### 8. manual — 도면 무관 (산출 대상 아님, 입력만 지원)
물푸기(hr), 품질관리비·준공도서비 등 경비성(식), 살수차·교통신호수(mth),
수압시험·기계기구설치(회), 장비운반, 시험발파, 보온양생(실적 정산)

## 지원 제외 (v1 범위 밖)
- **Ⅲ.기계 / Ⅳ.건축 / Ⅴ.전기·정보통신 공사** — 별도 분야
- 강교 제작·도장(전개면적), 비파괴검사 — 강구조 상세는 도면 기하 산출 부적합
- 그라우팅 주입량(TON — 지반 조건 의존), 관급자재 집계(BOQ 상위 집계로 파생 가능)

## 커버리지

사연댐 BOQ 산출 항목(계층 제목·자재 제외 약 480행) 기준:
유형 1~7로 **약 85%** 커버, manual 포함 시 산출서 구조 전체 재현 가능.

## 객체 중심 원칙 (레이어 비의존)

실무 도면은 레이어 규칙이 없거나 제각각이다. S-CUBE의 측정은 **처음부터 레이어가
아니라 CAD 객체(엔티티) 클릭 중심**으로 설계되어 있다:

- 측정 = 화면에서 폴리라인/해치/선/치수 **객체를 직접 클릭** → 기하에서 면적·연장 산출
- 레이어는 표시/숨김 필터일 뿐, 계산 경로에 관여하지 않음
- 레이어 규칙 기반 일괄 산출(Phase 5)은 **선택적 가속 기능** — 규칙이 없어도 전 기능 동작
- 폐합되지 않은 선분 조합도 Phase 5 자동 폐합 탐색(BOUNDARY 상당)으로 클릭 산출 예정

## DWG 직접 입력

사용자 대부분이 DWG를 그대로 올린다 → 서버에서 DWG→DXF 자동 변환 (원본 무손상,
임시폴더 처리). 변환 백엔드 우선순위:

1. **LibreDWG `dwg2dxf`** — 완전 무료·등록 불필요 (권장). 실도면 검증 완료
   ([실험 기록](./experiments/20260828-libredwg-real-dwg.md))
2. **ODA File Converter** — 폴백 (무료지만 다운로드 시 등록 필요)

미설치 시 웹 UI에서 설치 안내 모달 표시.
