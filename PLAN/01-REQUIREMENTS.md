# S-CUBE — 요구사항

## 1. 사용자 시나리오

### S1. 표준횡단면 기반 토공 수량산출
1. 도면(DXF) 로드 → 축척 캘리브레이션(기준 치수 2점 클릭, 실제값 입력)
2. 측점 No.0+000 횡단면도에서 절토부 폴리라인 클릭 → 면적 자동 산출
3. 성토부도 동일하게 클릭 → 측점별 단면 테이블에 자동 등록
4. 다음 측점 반복 (또는 레이어 규칙으로 일괄)
5. 측점 간 연장 자동 계산 → 양단면평균법으로 구간 체적 산출
6. 규격 입력(예: 유용토, 사토) → 수량산출서 출력

### S2. 구조물 단면 × 연장
1. 옹벽 표준도에서 콘크리트 단면 폴리라인 클릭 → 단면적
2. 평면도에서 옹벽 연장 라인 클릭 → 연장
3. 규격 입력(예: 콘크리트 25-24-15) → 체적, 거푸집 면적 산출

### S3. 검증 재산출
1. 기존 .scube 프로젝트 열기
2. 특정 항목 클릭 → 도면상 원본 객체가 하이라이트됨
3. 값 수정 시 하위 산출 자동 재계산 및 변경 이력 기록

## 2. 기능 요구사항

### FR-1. 도면 입력
| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-1.1 | DXF 파일(ASCII/Binary, R12~2018) 로드 | 필수 |
| FR-1.2 | DWG 드래그 시 변환 안내 메시지 표시 | 필수 |
| FR-1.3 | 레이어 목록 표시 및 표시/숨김 토글 | 필수 |
| FR-1.4 | 블록(INSERT) 재귀 전개 및 변환행렬 적용 | 필수 |
| FR-1.5 | 다중 도면 동시 로드(탭) | 선택 |
| FR-1.6 | ODA File Converter 연동 DWG 자동 변환 | 선택(Ph.5) |

### FR-2. 축척·단위
| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-2.1 | `$INSUNITS` 헤더 읽어 단위 추정 및 표시 | 필수 |
| FR-2.2 | 2점 클릭 + 실제 거리 입력으로 축척 캘리브레이션 | 필수 |
| FR-2.3 | 캘리브레이션 미완료 시 면적/연장 산출 차단 | 필수 |
| FR-2.4 | 도면별·뷰포트별 개별 축척 관리 | 필수 |
| FR-2.5 | 캘리브레이션 검증 (다른 치수와 대조하여 오차 표시) | 권장 |

### FR-3. 측정
| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-3.1 | 폐합 LWPOLYLINE/POLYLINE 클릭 → 면적 (shoelace) | 필수 |
| FR-3.2 | bulge(원호) 세그먼트 면적 보정 | 필수 |
| FR-3.3 | HATCH 경계 클릭 → 면적 | 필수 |
| FR-3.4 | 내부 구멍(island) 차감 | 필수 |
| FR-3.5 | LINE/POLYLINE 클릭 → 연장 | 필수 |
| FR-3.6 | DIMENSION 클릭 → 실측 좌표 거리 + override 텍스트 병기 경고 | 필수 |
| FR-3.7 | 다중 선택 합산 | 필수 |
| FR-3.8 | 열린 선분 자동 폐합 탐색 (tolerance snap + 그래프 순환) | 권장(Ph.5) |
| FR-3.9 | 측정 결과에 원본 엔티티 handle 저장(역추적) | 필수 |

### FR-4. 수량 산출
| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-4.1 | 단면적 × 연장 = 체적 | 필수 |
| FR-4.2 | 측점 관리 (No.x+xxx.xxx 표기 파싱·생성) | 필수 |
| FR-4.3 | 양단면평균법 구간 체적 V = (A1+A2)/2 × L | 필수 |
| FR-4.4 | 측점 불연속(전/후) 처리 — 동일 측점 2개 단면 | 필수 |
| FR-4.5 | 절토·성토 등 다중 항목 동시 관리 | 필수 |
| FR-4.6 | 각주법(원뿔대) 선택 옵션 | 선택 |
| FR-4.7 | 수동 입력 항목(도면 외 수량) 추가 | 필수 |

### FR-5. 규격 마스터
| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-5.1 | 규격 마스터 CRUD (공종/규격/단위/환산계수) | 필수 |
| FR-5.2 | 단위 환산 (㎥→ton 단위중량, m→본 정척) | 필수 |
| FR-5.3 | 할증률 적용 (철근 3%, 강재 5% 등) | 필수 |
| FR-5.4 | 사내 표준 규격 프리셋 내장 및 가져오기/내보내기 | 권장 |

### FR-6. 엑셀 출력
| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-6.1 | 수량산출서 시트: 공종/규격/단위/수량/산출근거 | 필수 |
| FR-6.2 | **산출근거 셀에 실제 엑셀 수식 삽입** (=(A1+A2)/2*L 형태) | 필수 |
| FR-6.3 | 측점별 상세 계산 시트 (구간별 전개) | 필수 |
| FR-6.4 | 집계표 시트 (공종별 합계, 수식 참조) | 필수 |
| FR-6.5 | 산출 메타(도면명, 축척, 산출일, 담당자) 헤더 | 필수 |
| FR-6.6 | 사용자 xlsx 템플릿에 값 채우기 | 선택 |

## 3. 비기능 요구사항

| ID | 항목 | 기준 |
|---|---|---|
| NFR-1 | 렌더 성능 | 10만 엔티티 도면 초기 렌더 3초 이내, 팬/줌 30fps 이상 |
| NFR-2 | 파싱 성능 | 50MB DXF 파싱 10초 이내 (Web Worker, UI 블로킹 없음) |
| NFR-3 | 정확도 | 면적 계산 오차 1e-9 상대오차 이내 |
| NFR-4 | 보안 | 도면 파일 외부 전송 없음. 로컬 서버는 127.0.0.1 바인딩 |
| NFR-5 | 오프라인 | 인터넷 연결 없이 전 기능 동작 |
| NFR-6 | 브라우저 | Chrome/Edge 최신 2개 버전 |
| NFR-7 | 언어 | UI 한국어. 코드/주석 영문, 도메인 용어는 한국어 병기 |

## 4. 제약 조건

- Node.js **24 LTS 이상** (개발 PC 확인: v24.18.1)
- Vite **8.0 이상** (Rolldown 번들러 기본 내장)
- Biome (ESLint/Prettier 미사용)
- 패키지 매니저: **pnpm** (workspace 사용)
- 원본 DWG는 읽기 전용, 절대 덮어쓰지 않음
