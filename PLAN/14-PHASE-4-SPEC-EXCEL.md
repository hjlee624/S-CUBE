## 검증 기준
- 출력 xlsx를 Excel에서 열었을 때 **모든 수량 셀이 수식**이고, 재계산해도 값이 동일
- 집계표 합계 = 수량산출서 합계 (수식 기반 자동 일치)
- 곡성 프로젝트 전체를 S-CUBE로 산출한 결과가 기존 워크북과 대조 통과
- 한글 서식 깨짐 없음, 인쇄 미리보기 정상
- **옹벽 1기 콘크리트 입력 시 거푸집·비계·동바리가 각 계산유형으로 자동 전개**되고,
  각 파생항목이 원본 콘크리트 항목까지 역추적됨 (계수 직접입력 없이 높이 1개만 판단)
- 8종 계산유형이 각 유형에 맞는 수식으로 생성되고, area-thickness 두께가 규격에서 옴
