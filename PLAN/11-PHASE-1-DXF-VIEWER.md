# Phase 1 — DXF 로드 · 렌더 · 캘리브레이션

**목표**: 실제 사내 도면을 열어 화면에서 보고, 축척을 맞춰 "거리 재기"가 되는 뷰어.

이 단계가 끝나면 **도면이 제대로 안 보이는 문제는 없어야** 한다.
이후 모든 기능이 이 렌더러 위에 얹힌다.

## 작업 항목

### 1-A. 파싱
- [ ] **P1-1** `dxf-parser` 도입 및 래핑 (`packages/core/src/dxf/parse.ts`)
- [ ] **P1-2** 정규화 레이어 — RawDxf → `NEntity[]` (03-DATA-MODEL 참조)
  - LINE, LWPOLYLINE, POLYLINE, ARC, CIRCLE, TEXT, MTEXT, HATCH, DIMENSION, SOLID
  - 미지원 엔티티는 무시하되 **개수를 집계해 UI에 표시** (조용히 버리지 않는다)
- [ ] **P1-3** 블록(INSERT) 재귀 전개
  - 변환행렬(위치·스케일·회전) 누적 적용, 순환 참조 방지 depth 제한
  - `EntityOrigin`으로 블록 경로 보존
- [ ] **P1-4** Web Worker 파싱 + 진행률 스트리밍
- [ ] **P1-5** `$INSUNITS`, `$MEASUREMENT` 헤더 읽어 단위 추정

### 1-B. 렌더링
- [ ] **P1-6** Canvas 2D 렌더러 (`apps/web/src/canvas/`)
  - world ↔ screen 좌표 변환, 팬(드래그)/줌(휠, 커서 기준)
  - bulge 폴리라인 → 원호 렌더
  - 레이어 색상(ACI 색인 → RGB), 선종류(파선/1점쇄선) 근사
- [ ] **P1-7** R-tree 공간 인덱스 + 뷰포트 컬링
- [ ] **P1-8** 레이어 패널 — 표시/숨김, 색상, 엔티티 수
- [ ] **P1-9** Zoom Extents / Zoom Window / 화면맞춤

### 1-C. 캘리브레이션
- [ ] **P1-10** 2점 클릭 → 실제 거리 입력 → `scale` 산출
  - 스냅 기능: 끝점/중점/교차점 (정확도 직결, 필수)
- [ ] **P1-11** 캘리브레이션 미완료 시 측정 도구 비활성화 + 배너 경고
- [ ] **P1-12** 검증 보조 — 도면 내 DIMENSION 하나를 선택하면
  캘리브레이션 기준 실측값과 치수 텍스트를 비교해 **오차 %** 표시
- [ ] **P1-13** 도면별 캘리브레이션 저장·복원

## 검증 기준
- 사내 실도면 5개(도로 횡단, 댐 단면, 옹벽 표준도, 배수구조물, 평면도) 로드 성공
- CAD에서 잰 치수와 S-CUBE 실측 거리 오차 **0.1% 이내**
- 10만 엔티티 도면 초기 렌더 3초 이내, 팬/줌 30fps 이상
- 미지원 엔티티 개수가 UI에 정확히 표시됨

## 리스크
- **블록 안의 블록 안의 단면** 구조가 흔하다. P1-3이 부실하면 좌표가 통째로 틀어진다.
  → 전개 결과를 CAD 화면과 스크린샷 대조하는 회귀 테스트를 fixtures로 만들어 둘 것.
- HATCH 경계 파싱은 DXF 스펙이 복잡하다. Phase 1에서는 **렌더만**, 면적 산출은 Phase 2.
