# Phase 6 — 검증 리포트 · 배포

**목표**: 산출 결과를 스스로 검증하고, 사내에 배포한다.

## 작업 항목

### 6-A. 검증 기능
> **전진 배치 주의**: P6-1 검증 리포트의 데이터구조·기본 집계는 Phase 4말~5의
> **내보내기 직전 통합 검증 게이트(P4-14)** 로 앞당겼다. Phase 6은 이를 리포트 문서로
> 정식화·확장한다. P6-3 감사로그의 최소 기록(FR-7.3)도 Phase 4말에 착수한다.

- [ ] **P6-1** 산출 검증 리포트 생성 (P4-14 `VerificationReport` 확장·정식화)
  - 결측 단면 / 결측 연장 목록
  - 캘리브레이션 미완료 도면
  - 치수 override 사용 항목
  - 자동 폐합으로 산출된 항목 (수동 확인 권장 표시)
  - `unsupportedCounts`·`sanitizedCount`(버려진 엔티티) 집계 노출
  - 이상값 (급변 단면적, 음수, 0)
  - 각 수량의 **역추적 체인**(item→basis→측정→handle) 열
- [ ] **P6-2** 두 프로젝트 비교(diff) — 설계 변경 전후 수량 대비표
- [ ] **P6-3** 감사 로그 — 각 수량의 생성·수정 이력 (FR-7.3 '권장→필수' 승격.
  store에 measurement/section 편집이력 최소 기록은 Phase 4말 착수)
- [ ] **P6-4** 검증 리포트 xlsx / 한글 출력

### 6-B. 품질
- [ ] **P6-5** 실도면 회귀 테스트 스위트 (fixtures 20건 이상, 익명화)
  - CAD/·Quantity_sample/ 실자료 익명화 파이프라인 로드맵 (프로젝트명·발주처 제거)
- [ ] **P6-6** Playwright E2E — 로드→캘리브→측정→산출→내보내기 전 흐름
  - CI 연결 스모크 1건(현재 e2e 스크립트만 있고 spec 0 → `playwright.config` + spec 추가)
  - **반자동 계측 훅**: 대표 워크플로 실행 중 **클릭 수·수기입력(타이핑) 횟수 계측**
    → NFR-8(수기입력 0%)·NFR-9(클릭 상한) **회귀 지표**
- [ ] **P6-7** 성능 벤치마크 자동화 (파싱·렌더·산출 시간 회귀 감시)
  - **반자동 벤치마크**: 표준횡단 1측점 절토/성토 산출 클릭 수 ≤4 회귀 감시(NFR-9),
    도면 유래 수치의 수기입력 횟수 0 회귀 감시(NFR-8)
- [ ] **P6-8** 에러 리포팅 — 로컬 로그 파일, 크래시 시 재현 정보 수집

### 6-C. 배포
- [ ] **P6-9** 배포 방식 결정
  - A안: 사내 웹서버 호스팅 + 로컬 서버 별도 설치 (업데이트 쉬움)
  - B안: Electron 단일 실행파일 (설치 간편, 오프라인 확실)
  - → Phase 6 착수 시점에 ADR로 확정
- [ ] **P6-10** 설치 가이드 + 사용자 매뉴얼 (스크린샷 포함)
- [ ] **P6-11** 사내 파일럿 — 진행 중 프로젝트 1건 병행 산출 후 결과 대조
- [ ] **P6-12** 교육 자료 (30분 분량)
- [ ] **P6-13** 피드백 수집 채널 및 이슈 트래킹 정비

### 6-D. 확장 검토 (v2 후보)

- [ ] 단가·내역서 연동

- [ ] 다중 사용자 협업

## 검증 기준
- 파일럿 프로젝트에서 기존 수작업 결과와 오차 0.1% 이내
- 산출 소요 시간 수작업 대비 1/3 이하
- 파일럿 참여자 3명 이상이 "실무에 계속 쓰겠다" 응답
