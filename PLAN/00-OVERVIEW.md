# S-CUBE — 프로젝트 개요

> **S-CUBE** (에스큐브) / *Saman Quantity Cube*
> 단면(㎡) × 연장(m) = 체적(㎥). 도면에서 바로 수량을 산출하는 토목 수량산출 도구.

---

## 1. 목적

토목 설계 도면(DWG/DXF)에서 단면적과 연장을 직접 취득하고, 재료 규격을 입력하면
**산출근거가 살아 있는 수량산출서(xlsx)** 를 자동 생성한다.

기존 수작업 흐름의 문제:

| 단계 | 현행 | 문제 |
|---|---|---|
| 단면적 취득 | CAD에서 AREA 명령 → 수기 전사 | 전사 오류, 이력 추적 불가 |
| 연장 산출 | 치수 읽어서 엑셀 입력 | 치수 override 값 오독 |
| 체적 계산 | 엑셀 수식 수작업 | 측점 불연속(전/후) 처리 실수 |
| 규격 반영 | 담당자 기억/개인 파일 | 표준 규격 불일치 |
| 검증 | 재계산 대조 | 산출근거 소실로 역추적 불가 |

S-CUBE는 이 5단계를 **한 화면에서 연결**하고, 모든 수량에 대해
"어느 도면의 어느 객체에서 나온 값인가"를 끝까지 추적 가능하게 유지한다.

## 2. 핵심 원칙

1. **완전자동을 목표로 하지 않는다.** 실무 도면은 폐합되어 있지 않고 레이어 규칙도
   제각각이다. S-CUBE는 *반자동* — 사람이 판단하고 도구가 계산·기록한다.
2. **모든 수량은 산출근거를 갖는다.** 엑셀 셀에 값이 아니라 **수식**이 들어간다.
   감리·발주처가 셀을 클릭하면 계산 과정이 보여야 한다.
3. **축척은 반드시 검증한다.** 캘리브레이션 없이 면적을 산출하지 않는다.
4. **원본 도면을 수정하지 않는다.** 읽기 전용. 산출 결과는 별도 프로젝트 파일에 저장.

## 3. 범위

### 포함 (In scope)
- DXF(R12~2018) 파싱 및 2D 렌더링
- 축척 캘리브레이션 (2점 기준선)
- 폐합 폴리라인 / HATCH 클릭 → 면적 자동 산출
- LINE / POLYLINE / DIMENSION 클릭 → 연장 산출
- 측점별 단면 관리 및 양단면평균법 체적 산출 (전/후 불연속 처리 포함)
- 재료 규격 마스터 및 단위 환산 (㎥→ton, m→본 등)
- 산출근거 상세형 수량산출서 xlsx 출력 (수식 삽입)
- 프로젝트 저장/불러오기 (.scube JSON)

### 제외 (Out of scope, v1)
- DWG 직접 파싱 → **DXF 변환 전제** (Phase 5에서 ODA 연동 검토)
- 3D / BIM(IFC) 연계
- 단가 산출, 일위대가, 내역서 작성
- 도면 편집·작도 기능
- 다중 사용자 동시 편집

## 4. 대상 사용자

- 1차: 삼안 토목 설계 담당자 (도로·수자원·댐 분야 수량산출 실무자)
- 2차: 물량 검토 담당, 감리 검증

## 5. 로드맵

| Phase | 내용 | 산출물 |
|---|---|---|
| 0 | 스캐폴딩·툴체인 | 빌드 가능한 모노레포 |
| 1 | DXF 로드·렌더·캘리브레이션 | 도면이 보이고 축척이 맞는 뷰어 |
| 2 | 면적·연장 측정 | 클릭으로 수치가 나오는 측정 도구 |
| 3 | 측점·구간·양단면평균법 | 체적 산출 엔진 |
| 4 | 규격 마스터 + 엑셀 출력 | **실무 투입 가능 최소 제품 (MVP)** |
| 5 | 자동 폐합 탐색·레이어 규칙 | 클릭 수 대폭 감소 |
| 6 | 검증 리포트·배포 | 사내 배포판 |

**Phase 4 완료 시점이 실무 투입 기준선.** Phase 5 이후는 생산성 개선.

## 6. 성공 기준

- 곡성·포천 수량산출 건을 S-CUBE로 재현했을 때, 기존 엑셀 결과와 **오차 0.1% 이내**
- 단면 1개 산출에 걸리는 시간이 수작업 대비 **1/3 이하**
- 산출된 xlsx를 열었을 때 모든 수량 셀이 **역추적 가능한 수식**을 포함
