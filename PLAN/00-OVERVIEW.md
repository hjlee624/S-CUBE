# S-CUBE — 프로젝트 개요

> **S-CUBE** (에스큐브) / *Saman Quantity Cube*
> 단면(㎡) × 연장(m) = 체적(㎥). 도면에서 바로 수량을 산출하는 토목 수량산출 도구.

---

## 1. 목적

토목 설계 도면(DWG/DXF)에서 단면적과 연장을 직접 취득하고, 재료 규격을 입력하면
**산출근거가 살아 있는 수량산출서(xlsx)** 를 자동 생성한다.

기존 수작업 흐름의 문제:

| 단계 | 현행 | 문제 |
|---|---|---|
| 단면적 취득 | CAD에서 AREA 명령 → 수기 전사 | 전사 오류, 이력 추적 불가 |
| 연장 산출 | 치수 읽어서 엑셀 입력 | 치수 override 값 오독 |
| 체적 계산 | 엑셀 수식 수작업 | 측점 불연속(전/후) 처리 실수 |
| 규격 반영 | 담당자 기억/개인 파일 | 표준 규격 불일치 |
| 검증 | 재계산 대조 | 산출근거 소실로 역추적 불가 |

S-CUBE는 이 5단계를 **한 화면에서 연결**하고, 모든 수량에 대해
"어느 도면의 어느 객체에서 나온 값인가"를 끝까지 추적 가능하게 유지한다.

## 2. 핵심 원칙

1. **반자동이 본질 — 사람은 클릭·판단만, 도구가 치수취득·계산·수식·양식을 자동으로.**
   기존 흐름은 도면의 치수를 눈으로 하나하나 읽어 값을 **수기 입력**하고, 수식을 넣고,
   양식을 맞추는 것이었다. S-CUBE는 이 **수기 입력을 탈피**한다. 완전자동을 목표로
   하지는 않는다(실무 도면은 폐합되어 있지 않고 레이어 규칙도 제각각) — 사람은
   도면에서 **어디를 클릭할지 판단**하고 결과를 **확인**하며, 나머지(치수 취득·계산·
   수식 생성·양식)는 전부 도구가 한다.
2. **도면상 수치는 사람이 텍스트를 읽어 옮기지 않는다.** 값은 항상 기하/좌표에서
   도구가 산출한다. 도면 텍스트(치수·주석)는 **검증·경고 용도로만** 대조한다
   (치수 override 경고 규칙의 일반화 — FR-3.6·R-5의 상위 근거). TEXT/MTEXT로만
   존재하는 수치(수량표·주석 치수)는 참고 표시·수동 확인 대상일 뿐, 자동 취득의
   1순위 경로가 아니다.
3. **레이어 규칙에 의존하지 않는다 — 객체(엔티티) 중심.** 분류·일괄화는 객체의
   기하·색상·선형·배치 근접성 등 **관측 가능한 속성 기반을 1순위**로 한다.
   레이어 규칙은 있으면 활용하는 **보조 가속 수단**일 뿐, 없어도 전 기능이 동작한다.
   (사용자가 DWG를 그대로 올리며 레이어 규칙이 없을 확률이 높다는 실무 전제 반영.)
4. **모든 수량은 산출근거를 갖는다.** 엑셀 셀에 값이 아니라 **수식**이 들어간다.
   감리·발주처가 셀을 클릭하면 계산 과정이 보여야 한다. 모든 수량은 도면 객체
   handle까지 **역추적** 가능하다.
5. **축척은 반드시 검증한다.** 캘리브레이션 없이 면적을 산출하지 않는다.
6. **원본 도면을 수정하지 않는다.** 읽기 전용. 산출 결과는 별도 프로젝트 파일에 저장.

## 3. 범위

### 포함 (In scope)
- DXF(R12~2018) 파싱 및 2D 렌더링, **DWG 직접 업로드**(LibreDWG 자동 변환, 원본 무손상)
- 축척 캘리브레이션 (2점 기준선)
- 폐합 폴리라인 / HATCH 클릭 → 면적 자동 산출
- **원지반선·계획선 2클릭 → 절토/성토 단면적 자동 산정 → 측점 자동 기입** (FR-3.10)
- LINE / POLYLINE / DIMENSION 클릭 → 연장 산출
- 측점별 단면 관리 및 양단면평균법 체적 산출 (전/후 불연속 처리 포함, 측점 번호만 입력 허용)
- BOQ 계산유형 분류(8종)에 따른 다공종 수량식 자동 생성 + 규격 프리셋
- **파생 수량 반자동 취득** — 거푸집(접촉면)·비계(외주×높이)·동바리(면적×높이)
- 재료 규격 마스터 및 단위 환산 (㎥→ton, m→본 등)
- 산출근거 상세형 수량산출서 xlsx 출력 (수식 삽입)
- 다중도면 워크스페이스(탭) + 수량 작업대 별도 창(Document PiP)
- 프로젝트 저장/불러오기 (.scube JSON)

### 제외 (Out of scope, v1)
- 3D / BIM(IFC) 연계
- 단가 산출, 일위대가, 내역서 작성
- 도면 편집·작도 기능
- 다중 사용자 동시 편집

## 4. 대상 사용자

- 1차: 삼안 토목 설계 담당자 (도로·수자원·댐 분야 수량산출 실무자)
- 2차: 물량 검토 담당, 감리 검증

## 5. 로드맵

| Phase | 내용 | 산출물 | 상태 |
|---|---|---|---|
| 0 | 스캐폴딩·툴체인 | 빌드 가능한 모노레포 | ✅ 완료 |
| 1 | DXF/DWG 로드·렌더·캘리브레이션 | 도면이 보이고 축척이 맞는 뷰어 | ✅ 완료 |
| 2 | 면적·연장 측정 | 클릭으로 수치가 나오는 측정 도구 | ✅ 완료(HATCH 면적 미지원 잔존) |
| 3 | 측점·구간·양단면평균법 | 체적 산출 엔진 | ✅ 완료 |
| 4 | 규격 마스터 + 엑셀 출력 | **실무 투입 가능 최소 제품 (MVP)** | ✅ 완료 |
| 5 | 자동 폐합 탐색·객체 기반 일괄·DWG 직접입력 | 클릭 수 대폭 감소 | ⏳ 미착수 |
| 6 | 검증 리포트·배포 | 사내 배포판 | ⏳ 미착수 |

**Phase 4 완료 = 실무 투입 기준선 도달(MVP).** Phase 5 이후는 반자동 완결·생산성 개선.

### 완료 이후 추가 반영(감사 기준)
- BOQ 계산유형 **8종** + 프리셋 **74종** (양단면평균법 외 다공종 커버 — [quantity 문서](../docs/quantity-calc-taxonomy.md))
- 다중도면 워크스페이스(탭) + 필수도면 체크리스트, 수량 작업대 **별도 창(Document PiP)**
- 웹 유입용 동적/모션 디자인 언어, 측점 **번호만 입력** 허용
- **진행 중(별도 워크플로)**: 원지반선·계획선 **2클릭 → 절토/성토 자동 단면적 → 측점 자동 기입** (FR-3.10)

> 남은 작업의 우선순위 로드맵은 [22-REMAINING.md](./22-REMAINING.md) 참조.

## 6. 성공 기준

- 곡성·포천 수량산출 건을 S-CUBE로 재현했을 때, 기존 엑셀 결과와 **오차 0.1% 이내**
- 단면 1개 산출에 걸리는 시간이 수작업 대비 **1/3 이하**
- 산출된 xlsx를 열었을 때 모든 수량 셀이 **역추적 가능한 수식**을 포함
- **[반자동] 도면에서 취득 가능한 모든 수치**(단면적·연장·측점 chainage 등)는
  **수기 타이핑 0회** — 사람은 클릭·판단·확인만 한다. 수기 입력은 도면 외 수량
  (FR-4.7)으로만 한정된다.
- **[반자동] 표준횡단 1측점의 절토/성토 산출**을 **N클릭 이하**로 완료한다
  (목표치 **≤4클릭**: 원지반선 클릭·계획선 클릭·측점 확인·저장). Phase 6 벤치마크에서
  대표 워크플로별 클릭 수·수기입력 횟수를 계측해 **회귀 감시**한다(NFR-8·9).
