# Phase 3 — 측점 · 구간 · 체적 산출

**목표**: 측점별 단면적이 모이면 양단면평균법으로 체적이 자동으로 나온다.
곡성·포천 엑셀에서 하던 계산을 도구가 대신한다.

## 작업 항목

### 3-A. 측점 처리 (`packages/core/src/station/`)
- [ ] **P3-1** 측점 식별자 생성 — **번호·라벨만으로도 생성 가능**, `+거리` 표기는 선택
  - `No.8+0.000`, `No.8+000`, `8+0.000`, `STA.0+120.5`, `No.8+0.000(전)` 변형 수용
  - **번호만**(예: `8`) 또는 자유 라벨만 입력해도 유효 (03-DATA-MODEL §4 — 표기규격
    미준수 측점도 1급 허용, `No.8+0.000` 강제 아님)
  - 상세표기 파싱 실패는 조용히 넘기지 말고 **입력 오류로 표시**하되, 번호만 폴백은 정상 경로
- [ ] **P3-2** 측점 → chainage(m) 환산
  - 번호만 있을 때: `chainage_m = 번호 × stationInterval_m` (프로젝트 설정, 기본 20m)
  - `+거리`가 있으면 **가산**: `chainage_m = 번호 × interval + plus_m`
- [ ] **P3-3** 정렬 및 중복 검출 (정렬 키는 `chainage_m`)
- [ ] **P3-4** 전/후 불연속 처리 (03-DATA-MODEL §4 규칙 그대로 구현)
  - `(전)` 단면 결측 시 **에러로 승격**, 산출 차단
- [ ] **P3-5** 도면 제목 TEXT 측점 자동 인식 — **FR-3.10의 필수 종속 작업**(보조→승격)
  - 횡단면 프레임 근처 TEXT를 측점 패턴(`parseStation` 재사용)으로 인식
  - 2클릭 취득한 cut/fill 단면적을 인식된 측점의 `StationSection`에 **자동 배정**
    (항상 **사용자 확인식** — 자동 확정 금지)
  - 인식 실패 시 **번호만 입력 폴백** 유지. Phase 5 P5-15/16(배치 패턴 인식)과 연계

### 3-B. 체적 계산 (`packages/core/src/quantity/`)
- [ ] **P3-6** 양단면평균법 `V = (A1+A2)/2 × L`
- [ ] **P3-7** 각주법(원뿔대) 옵션 `V = L/6 × (A1 + 4Am + A2)`
- [ ] **P3-8** 항목(itemKey)별 독립 산출 — 절토/성토/표토제거/암깎기 등
- [ ] **P3-9** 구간 자동 생성 — 인접 측점 쌍으로 Segment 생성, 결측 구간 표시
- [ ] **P3-10** `FormulaNode` 트리 생성 — 숫자가 아니라 계산식으로 결과 보관
- [ ] **P3-16** **절토/성토 프로파일 2클릭 자동 산정** (FR-3.10 — 반자동 핵심)
  - 원지반선 클릭 + 계획선 클릭(2클릭) → 두 프로파일 사이 폐구간 자동 구성
  - 교차점(breakpoint) 기준 **부호 분리**: 계획선이 원지반보다 아래=절토, 위=성토
  - 절토/성토 단면적을 각각 산정 → 활성 측점의 절토/성토 항목에 자동 기입
    (`Measurement.method = 'profile-cut-fill'`, `cutFill` 필드로 구분)
  - **P5-1~3의 임의 클릭점 face 탐색과는 별개 알고리즘** — 두 프로파일 차집합 적분
  - 이미 배선된 구현 참조: HeaderBar 'section-area' 도구, `canvas/actions.ts` 2클릭
    오케스트레이션, `apps/web/src/lib/section-area.ts`, `CanvasStage` 디스패치,
    `core/profile-area.ts` `areaBetweenProfiles`
  - 검증기준: **수동 폐합 면적과 오차 1e-6**, 교차 breakpoint 정확성,
    warnings(공통 x구간 없음·비단일값 x)이 UI에 노출

## 검증 기준
- **곡성·포천 기존 엑셀 워크북을 S-CUBE로 재현 → 총 체적 오차 0.1% 이내**
  (이 검증이 Phase 3의 존재 이유. 통과 못하면 다음 단계로 안 넘어간다)
- 전/후 불연속 구간의 체적이 중복 계상되지 않음
- 결측 단면이 있을 때 조용히 0으로 처리되지 않고 반드시 에러로 노출됨
- **번호만 입력한 측점**도 chainage가 올바르게 파생되고 정렬·구간 생성이 정상 동작
- **2클릭 절토/성토 산정(P3-16)** 결과가 수동 폐합 면적과 오차 1e-6 이내이고,
  제목 TEXT 인식으로 활성 측점에 자동 기입됨(사용자 확인 후)
