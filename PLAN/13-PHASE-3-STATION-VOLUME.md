# Phase 3 — 측점 · 구간 · 체적 산출

**목표**: 측점별 단면적이 모이면 양단면평균법으로 체적이 자동으로 나온다.
곡성·포천 엑셀에서 하던 계산을 도구가 대신한다.

## 작업 항목

### 3-A. 측점 처리 (`packages/core/src/station/`)
- [ ] **P3-1** 측점 표기 파서
  - `No.8+0.000`, `No.8+000`, `8+0.000`, `STA.0+120.5`, `No.8+0.000(전)` 등 변형 수용
  - 파싱 실패 시 조용히 넘기지 말고 **입력 오류로 표시**
- [ ] **P3-2** 측점 → chainage(m) 환산 (`stationInterval_m` 프로젝트 설정, 기본 20m)
- [ ] **P3-3** 정렬 및 중복 검출
- [ ] **P3-4** 전/후 불연속 처리 (03-DATA-MODEL §4 규칙 그대로 구현)
  - `(전)` 단면 결측 시 **에러로 승격**, 산출 차단
- [ ] **P3-5** 도면 텍스트에서 측점 자동 인식 (횡단면도 제목 TEXT 파싱) — 보조 기능

### 3-B. 체적 계산 (`packages/core/src/quantity/`)
- [ ] **P3-6** 양단면평균법 `V = (A1+A2)/2 × L`
- [ ] **P3-7** 각주법(원뿔대) 옵션 `V = L/6 × (A1 + 4Am + A2)`
- [ ] **P3-8** 항목(itemKey)별 독립 산출 — 절토/성토/표토제거/암깎기 등
- [ ] **P3-9** 구간 자동 생성 — 인접 측점 쌍으로 Segment 생성, 결측 구간 표시
- [ ] **P3-10** `FormulaNode` 트리 생성 — 숫자가 아니라 계산식으로 결과 보관

### 3-C. UI
- [ ] **P3-11** 측점 테이블 — 행: 측점, 열: 항목별 단면적. 인라인 편집
- [ ] **P3-12** 측정 결과를 셀에 드래그/할당하는 흐름
- [ ] **P3-13** 구간 계산 결과 테이블 (연장, 평균단면적, 체적)
- [ ] **P3-14** 종단 프로파일 미니 그래프 (측점 vs 단면적) — 이상값 시각 검출
- [ ] **P3-15** 이상 감지 배지
  - 인접 단면적이 3배 이상 급변
  - 연장이 표준 측점 간격과 크게 다름
  - 단면적 0 또는 음수

## 검증 기준
- **곡성·포천 기존 엑셀 워크북을 S-CUBE로 재현 → 총 체적 오차 0.1% 이내**
  (이 검증이 Phase 3의 존재 이유. 통과 못하면 다음 단계로 안 넘어간다)
- 전/후 불연속 구간의 체적이 중복 계상되지 않음
- 결측 단면이 있을 때 조용히 0으로 처리되지 않고 반드시 에러로 노출됨
